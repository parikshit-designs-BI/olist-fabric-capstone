- Local Desktop instance `olist_capstone` has **no local model** — the PBIX is a live connection, so Desktop refresh only re-queries Fabric; it cannot pull new data by itself.

## Lessons / gotchas captured today
1. **Live connection ≠ refresh.** Desktop refresh on a live-connected Direct Lake model does not reframe the model. Reframe happens in the service (auto on Delta overwrite, or manual refresh).
2. **Dropping a Delta table breaks Direct Lake framing.** After `DROP TABLE` + recreate: wait for SQL endpoint sync, then refresh the semantic model explicitly.
3. **Model columns must exist in the Delta table first.** Add the column in gold, run the notebook, *then* add it to the model.
4. `03_gold_build` must be saved before the pipeline runs — the pipeline executes the saved version.
5. Verify each layer with one cell (bronze file max date → silver max date → gold table exists/count) before touching the model; it localises the break in 20 seconds.
